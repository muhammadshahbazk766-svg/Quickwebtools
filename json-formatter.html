What is JSON?

JSON (JavaScript Object Notation) is a lightweight data format that's easy for humans to read and write, and easy for machines to parse and generate. It's based on a subset of the JavaScript programming language but is independent of any programming language.

JSON Structure

JSON is built on two basic structures:

  • Objects: Unordered collections of key/value pairs, enclosed in curly braces {}
  • Arrays: Ordered lists of values, enclosed in square brackets []

Data Types in JSON

  • String: Text enclosed in double quotes: "hello"
  • Number: Integer or float: 42, 3.14
  • Boolean: true or false
  • Null: Represents empty or no value: null
  • Object: {"key": "value"}
  • Array: [1, 2, 3]

Why Use JSON?

  • Lightweight and efficient for data transmission
  • Easy to read and write for humans
  • Supported by virtually all programming languages
  • Industry standard for APIs and web services
  • Used by most modern applications

How to Format JSON

Unformatted JSON (Minified)

{"name":"John","age":30,"city":"New York","hobbies":["reading","gaming"]}

Formatted JSON (Pretty-Printed)

{ "name": "John", "age": 30, "city": "New York", "hobbies": [ "reading", "gaming" ] }

Our formatter adds proper indentation and line breaks to make JSON more readable. This is especially useful for large or complex JSON data.

JSON Examples

Example 1: Simple Object

{ "firstName": "John", "lastName": "Doe", "email": "john@example.com" }

Example 2: Array of Objects

{ "users": [ {"id": 1, "name": "John", "active": true}, {"id": 2, "name": "Jane", "active": false}, {"id": 3, "name": "Bob", "active": true} ] }

Example 3: Nested Objects

{ "user": { "profile": { "name": "John Doe", "location": { "city": "New York", "country": "USA" } } } }

Frequently Asked Questions

What's the difference between formatting and minifying? ▼

Formatting adds indentation and line breaks to make JSON readable by humans. Minifying removes all unnecessary whitespace to reduce file size for storage or transmission. Both represent the same data.

What does "invalid JSON" mean? ▼

Invalid JSON means the syntax doesn't follow the JSON specification. Common errors include: missing quotes around keys, single quotes instead of double quotes, trailing commas, unmatched braces or brackets, or unescaped special characters.

Can I use this for API responses? ▼

Yes! This tool is perfect for working with API responses. Copy the JSON response from your API, paste it here, and click "Format" to make it readable. You can also validate to check if the response is valid JSON.

How large can JSON files be? ▼

Our formatter works with large JSON files, but very large files may take a moment to process. For the best experience, keep files under a few MB. Extremely large files (over 10MB) may need to be processed in your code or a specialized tool.

Is my JSON data stored or seen by anyone? ▼

No! All processing happens in your browser. Your JSON data is never sent to any server or stored anywhere. Your data and privacy are completely protected.

What characters need escaping in JSON? ▼

In JSON strings, these characters must be escaped: quotation marks ("), backslashes (\), newlines (\n), tabs (\t), and control characters. For example, to include a quotation mark in a string: "He said \"Hello\"" or to include a backslash: "Path: C:\\Users"
